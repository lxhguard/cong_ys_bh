# 防抖节流

## 一、防抖 · 精简版（最常用面试答案）

```js
function debounce(fn, delay = 300) {
  let timer = null;
  return function (...args) {
    clearTimeout(timer);                            // 重置计时器
    timer = setTimeout(() => fn.apply(this, args), delay);
  };
}
```

带 `immediate` 的经典版（首次立即执行，也常考）：

```js
function debounce(fn, delay = 300, immediate = false) {
  let timer = null;
  return function (...args) {
    const callNow = immediate && !timer;           // 冷却期内不重复触发
    clearTimeout(timer);
    timer = setTimeout(() => {
      timer = null;
      if (!immediate) fn.apply(this, args);        // trailing：停止后执行最后一次
    }, delay);
    if (callNow) fn.apply(this, args);             // leading：首次立即执行
  };
}
```

## 二、节流 · 精简版（两个都要会）

**时间戳版**（首帧立即执行、尾部可能丢）：

```js
function throttle(fn, delay = 300) {
  let last = 0;
  return function (...args) {
    const now = Date.now();
    if (now - last >= delay) {
      last = now;
      fn.apply(this, args);
    }
  };
}
```

**定时器版**（延迟执行、尾部兜底执行一次）：

```js
function throttle(fn, delay = 300) {
  let timer = null;
  return function (...args) {
    if (!timer) {
      timer = setTimeout(() => {
        timer = null;
        fn.apply(this, args);
      }, delay);
    }
  };
}
```

## 三、选版口诀（面试时直接背）

| 问法 | 给哪个 |
|---|---|
| 「写个防抖」 | 精简版即可；主动补一句 `immediate` 参数是加分 |
| 「写个节流」 | 两个版本都写，讲清「时间戳版丢尾部、定时器版兜底」 |
| 「防抖和节流区别」 | 一句话：**防抖认最后一次，节流固定频率** |
| 「按钮防重复提交」 | 防抖 + immediate（leading） |

**提醒**：简单版能过基础关，但既然你目标是 P6/P7，动笔前加一句「我按基础版写，如果要支持 leading/trailing、cancel、flush 我也可以给完整版」——这句话的成本为零，面试官对「知道完整版长什么样」的候选人印象完全不同。
