从输入 URL 到页面加载 · 面试链路图
8 阶段标准答案 · 每阶段右侧挂追问点；底部为你的实战差异化话术
① URL 输入
补全协议 · HSTS · 解析 scheme/host/port/path
② DNS 解析
缓存逐级：浏览器→OS/hosts→本地DNS（递归）→根/顶级/权威（迭代）追问：递归vs迭代 / UDP53 / 劫持
③ TCP + TLS
三次握手建连；HTTPS 再走 TLS 握手（证书链校验 → 非对称交换对称密钥，1.3 可 1-RTT）追问：为什么3次不是2次 / 4次挥手 / 队头阻塞
④ HTTP 请求
请求行+请求头+请求体；keep-alive 复用连接 追问：GET/POST / 请求头字段 / 正文格式
⑤ 服务器响应
状态码（2xx/3xx/4xx/5xx）+ 响应头 + 响应体；缓存命中返回 304 或直接强缓存 追问：301vs302 / 强vs协商缓存 / ETag
⑥ 解析渲染
DOM + CSSOM → Render Tree → Layout → Paint → Composite；JS 阻塞，async/defer 控制；preload scanner 预下载 追问：回流优化 / 宏微任务 / asyncvsdefer
⑦ 完成事件
DOMContentLoaded → load；体验指标看 FP / FCP / LCP 追问：两事件区别 / LCP 影响因素
⑧ 连接管理
Keep-Alive 复用 / HTTP2 多路复用 / HTTP3 QUIC 无队头阻塞；结束后四次挥手
你的实战话术落点：⑥渲染 ← 伪 SSR 剥离 pageinit chunk 前置直出（FCP 1.5s→160ms）、DynamicScriptTagPlugin 修 iOS 闪白、batchedUpdates 合并 20 次 setState；④请求 ← PIA Worker 并行预取 + Snapshot（FCP 4s→2.1s）；⑥合成层 ← 低端机治理 142MB→24.1MB（Arco Tabs 节能模式）。答完链路后接这一段，即「背过 → 做过」。
